# Product

## Register

product

## Users
High-end Photo Booth rental companies, event photographers, and their premium clients (weddings, corporate events). The context is a professional Admin Studio for customizing templates, and a Front-end Client Library where clients review and select their templates.

## Product Purpose
A $10,000-tier premium Photo Booth template selection and customization engine. It provides a flawless, "minimal yet immersive" workflow for both the admin and the end-client. Success is defined by perfect visual alignment, real-world applicability (layouts that actually sell), and a breathtaking client experience.

## Brand Personality
Wabi-Sabi, handcrafted heirlooms, Filipino heritage (Barong Tagalog, ancestral weaving, Piña Ecru). The voice is elegant, restrained, and deeply rooted in craftsmanship and perseverance.

## Anti-references
- "Generic beige" or cheap Canva-style templates.
- Jagged, unpolished edges.
- "Tiny square" media slots that don't maximize photo space or aren't practical for real-world print sales.
- Cluttered UI with default AI-generated scaffolding (e.g., repeating numbered eyebrows).

## Design Principles
- **Wabi-Sabi Elegance:** Embrace organic textures (like hand-loomed pineapple fiber) over sterile perfection.
- **Flawless Utility:** Every layout must be mathematically centered and real-world applicable. No dead space.
- **Minimal Yet Immersive:** The interface should vanish, allowing the premium quality of the templates to be the focal point.

## Accessibility & Inclusion
- Clear visual hierarchy with appropriate contrast for administrative tasks.
- Responsive, pixel-perfect alignment across all devices for the client-facing gallery.
